# CreativeMKStudios

George Childs Gatty builds websites for small businesses in Milton Keynes and Bedfordshire.

The sites are written to show up on Google. The price is per month, based on the number of pages, and paid once a year. There is no upfront build cost. Small changes are included.

Email: [creativemkstudios@gmail.com](mailto:creativemkstudios@gmail.com)

## Site

This repository is the studio website, built with Astro.

```bash
npm install
npm run dev
npm run build
```

Prices, page copy, and contact details live in `src/data/site.ts`. The public site address is set in `astro.config.mjs`.
